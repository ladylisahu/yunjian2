# 水镜运见 2.0 · yunjians.com

融合东方星象历法命理（老黄历、五行穿衣指南、八字紫微、大运流年、灵签）、西洋占星（十日趋势、十二星座今日榜、缘分合盘、1/3张塔罗）、理性复盘对账与「水镜先生」上下文感知 AI 智能体的轻量单页应用。

## 核心功能

- **免登录个人生辰档案**：一次填写、本地保存、全站 6 大模块与 AI 智能体实时联动。
- **今日运势 · 黄历 · 五行穿衣指南**：确定性五维日运（同人同日恒定）、公农历干支节气宜忌、五档五行穿衣色系与今日生肖吉凶、十二时辰黄道吉凶。
- **八字紫微 · 大运流年**：四柱五行频谱、十天干日主命格、紫微十四主星、近 5 年流年运势与人生大运时间轴。
- **趋势 · 十二星座今日榜**：前后 10 日发光 SVG 趋势曲线 + 十二星座今日好运 1–12 排行与详情联动。
- **缘分合盘**：西洋星座相位配对 + 东方生肖三合/六合测算。
- **灵签 · 塔罗**：水镜灵签摇签解诗 + 每日塔罗（支持抽 1 张今日指引 & 抽 3 张过去/现在/未来牌阵）。
- **复盘对账**：白天预测分 vs 夜间真实体感分打分记录，自动统计平均吻合度（近 90 天本地保存）。
- **水镜先生 AI 智能体**：常驻白胡子古装老者（3 款形象随心切换），实时感知全站排盘与复盘数据，内置本地智能推演引擎并支持一键接入 OpenAI / DeepSeek 兼容大模型 API。
